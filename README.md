# SmartDivert

SmartDivert is a modern SaaS landing page built with Next.js, Tailwind CSS, and Framer Motion. It highlights call routing features, compares Smart (Free) and Enterprise (Cloud) plans, and presents a polished responsive experience for modern teams.

## Features

- Fully responsive Next.js app using the App Router
- Animated UI with Framer Motion
- Clean, reusable component structure
- Tailwind CSS utility styling
- Conversion-focused sections and pricing
- Production-ready build configuration

## Local Setup

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
```

## Deployment

This project is ready for deployment on platforms like Vercel or Netlify.

### Vercel

1. Connect your GitHub repository.
2. Set the framework to `Next.js`.
3. Deploy.

### Manual

```bash
npm run build
npm start
```
